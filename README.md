# Lush & Sage

A modern fashion e-commerce homepage built using React.js and CSS.

## Features

- Responsive Navigation Bar
- Hero Section
- Categories Section
- Featured Products
- Customer Testimonials
- Footer

## Technologies Used

- React.js
- Vite
- CSS3
